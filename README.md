🎨 LogoForge 1.1 — Beta Test

Представляем новую версию LogoForge — редактора фотографий и конструктора логотипов!

Создавайте собственные дизайны, редактируйте изображения и воплощайте творческие идеи с помощью удобных инструментов.

✨ Возможности:

- Конструктор с фигурами, иконками и текстом.
- Импорт фотографий из галереи.
- Работа со слоями.
- Поворот, масштабирование и настройка прозрачности.
- Создание логотипов с помощью ИИ.
- Готовые шаблоны для быстрого старта.
- Настройка внешнего вида проекта.
